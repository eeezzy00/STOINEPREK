# Despot's Arena — Контекст проекта для Claude

## Что это за игра
2D action roguelite в тёмном фэнтези сеттинге. Ориентир по геймплею — **Katana Zero**: быстрый экшн, pixel art, атмосфера dark fantasy.

Жанр: Idle Auto-Battler Roguelite  
Сеттинг: Dark Fantasy (подземелья, монстры, тёмный юмор)  
Визуал: Dark Chibi Pixel Art, спрайты 64×64px  
Движок: Godot 4

## Схема работы
- **Claude** — пишет весь код (GDScript), создаёт скрипты, исправляет баги
- **Пользователь** — создаёт сцены в Godot, тестирует, говорит что поменять
- Язык общения: русский
